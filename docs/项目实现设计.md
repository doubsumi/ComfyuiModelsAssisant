# 项目实现设计

## 0. 新增决策的落地

### 0.1 GraphPattern 的混合存储（决策 1-C）

```
data/graph_patterns/
├── builtin/                    # 内置只读，随代码版本管理
│   ├── krea2_t2i.json
│   ├── boogu_t2i.json
│   ├── minimax_h3_fl2va.json
│   └── minimax_h3_ref2va.json
└── custom/                     # 用户自定义，可编辑
    └── <user-defined>.json
```

**规则**：

- 启动时两个目录都加载，`builtin` 优先级低
- 同名 ID 时，`custom` 覆盖 `builtin`
- 前端「另存为」只能存到 `custom/`
- 前端「重置为内置」时，删除 `custom/` 下的同名文件

### 0.2 前端可配阈值（决策 2）

新增 `data/config.json`：

```json
{
  "confidenceThreshold": 0.6,
  "scanCacheMaxAge": 300,
  "patchHistoryRetention": 100,
  "comfyuiRoot": "E:\\ComfyUI_windows_portable_nvidia\\ComfyUI_windows_portable\\ComfyUI",
  "modelsDir": "E:\\ComfyUI_windows_portable_nvidia\\ComfyUI_windows_portable\\ComfyUI\\models",
  "port": 17890
}
```

**关键字段说明**：

- `confidenceThreshold`：`needsLlm` 的判定阈值，前端可调
- `scanCacheMaxAge`：扫描缓存有效期（秒）
- `patchHistoryRetention`：Patch 历史最多保留多少条
- `comfyuiRoot`：用于推导 workflows 目录和 custom\_nodes 目录

**前端新增设置面板**：

```
┌─ 设置 ──────────────────────────────────┐
│ 架构识别置信度阈值   [====|====] 0.60   │
│   低于此值的模型将进入待 LLM 补全列表     │
│                                          │
│ 扫描缓存有效期       [___] 秒             │
│                                          │
│ Patch 历史保留条数   [___] 条             │
│                                          │
│ ComfyUI 根目录       [___________] [浏览] │
│                                          │
│ [保存] [恢复默认]                         │
└──────────────────────────────────────────┘
```

### 0.3 Patch 历史整体回滚（决策 3-A）

- `PatchHistory` 只实现 `getRollbackDiff(patchId)`，返回整体回滚所需的字段变更
- 前端只提供「回滚到此 Patch 之前」按钮
- 不做条目级回滚

## 6. 风险与前置准备

### 6.1 前置准备（开始 M0 之前）

1. **确认** **`data/architectures.json`** **的初始内容**——包含哪些架构，每个架构的字段值。
2. **确认 4 个内置图谱模式的节点结构**——它们需要从你的实际工作流中提炼，但不是简单的复制。
3. **`clipType`** **参数值的确认**——Krea2 用 `krea2`、Boogu 用 `boogu`、MiniMax 用 `minimax`，这些是 `CLIPLoader` 的 `type` 字段值。需要验证它们在你的 ComfyUI 版本中确实存在。

### 6.2 关键风险

| 风险                    | 触发点   | 缓解                                   |
| --------------------- | ----- | ------------------------------------ |
| Layer 1b 准确率不足        | M1 验证 | 先跑一遍，根据实际结果调整 `ARCH_SIGNATURES`      |
| 图谱模式生成的 JSON 加载失败     | M5 验证 | 每个图谱必须先手动在 ComfyUI 跑通再定型             |
| LoRA 链的 links 构建有误    | M5 验证 | `WorkflowSerializer.validate()` 自检兜底 |
| Patch 校验过严导致 LLM 输出被拒 | M2 验证 | 先宽松（warning 不阻塞），根据实际情况收紧            |
| 前端状态同步复杂              | M4/M5 | 集中式 state + 事件总线，避免散乱更新              |
